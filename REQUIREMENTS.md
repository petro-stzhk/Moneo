# Moneo requirements

### Design

A **clean, modern, minimal SaaS-style dashboard** focused on clarity and fast interaction.

* **Light theme** with white/very light gray background.
* Dark text with **one primary accent color**.
* Left sidebar navigation on desktop:

  * Dashboard
  * Transactions
  * Budgets
  * Debts
  * Goals
  * Settings
* Responsive mobile layout with bottom navigation.
* Rounded cards, subtle borders/shadows, generous spacing.
* Simple charts, progress bars, and status indicators.
* Prominent **“+ Add Transaction”** button.
* Currency: configurable, default **PLN**.
* English UI throughout.

### MVP Functionality

**Dashboard**

* Current balance
* Income / expenses for current month
* Remaining monthly budget
* “Safe to spend” amount
* Daily spending limit until next payday
* Upcoming payments
* Debt summary
* Savings goal progress
* Recent transactions

**Transactions**

* Add / edit / delete transaction
* Income or expense
* Amount
* Category
* Date
* Account
* Note
* Search and filters
* Categories

**Budgets**

* Monthly budget
* Category budgets
* Spent vs. remaining
* Progress indicators
* Overspending warnings

**Debts**

* Add debt
* Creditor
* Total amount
* Paid amount
* Remaining amount
* Due date
* Priority
* Mark as paid

**Savings Goals**

* Goal name
* Target amount
* Current amount
* Progress %
* Add money / withdraw money
* Optional deadline

**Settings**

* Currency
* Monthly income / payday
* Categories
* Accounts
* Basic profile settings

### MVP principle

The app should answer **three questions immediately**:

> **How much money do I have?**
> **How much can I safely spend?**
> **Where is my money going?**

Everything else can come later.
